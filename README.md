# 赛马娘育成策略算法实验室（uma-algo-lab）

**一句话：模拟器是固定黑盒，这个仓库专门回答一个问题——GA 调参已经收敛之后，换别的算法还能不能再把评分往上挤？**

## 为什么开这个仓库

- 私有仓库额度吃紧，这里是**公开仓库**。
- 模拟器（[xulai1001/umaai-rs](https://github.com/xulai1001/umaai-rs)）逻辑**一行都不改**。所有实验通过它的命令行工具 `bench_base` 做评估：我们把一份"参数覆盖层"（基因组 TOML）喂给它，它跑育成回分数。模拟器是考场，我们只在考场外面换着花样猜答案。
- GA（在模拟器仓库里）已经证明：同样的代码同样的马，跑多少轮都收敛到同一个基因组——**在当前 70 个参数旋钮上，GA 已经拧到头了**。想再提分只有两条路：换更精细的优化算法，或者给模拟器加新参数维度。本仓库干前者。

## 架构

```
┌────────────────────────────────────────────────────┐
│  optimizers/  四个赛马选手（同一接口，同预算比赛）      │
│   cmaes（协方差自适应进化） tpe（贝叶斯优化）           │
│   sa（模拟退火）           cem（交叉熵法）             │
└──────────────────┬─────────────────────────────────┘
                   │ ask()/tell()，全部在 [0,1] 的 47 维归一化空间
┌──────────────────▼─────────────────────────────────┐
│  lab/space.py    70 字段搜索空间（与 Rust 参数一一对应）│
│  lab/genome.py   向量 ⇄ 基因组 ⇄ TOML（对偶 Rust 解析）│
│  lab/evaluator.py 评估总线：CRN 同种子 / 缓存 / holdout│
└──────────────────┬─────────────────────────────────┘
                   │ subprocess 调 bench_base --genome-file x.toml
┌──────────────────▼─────────────────────────────────┐
│  umaai-rs 模拟器（黑盒，逻辑零修改）                    │
│  smoke 档: 3 种子 × 20 局   full 档: 7 × 60 + holdout │
│  fitness = 平均分 − 800 × 比赛失败率（与 GA 同式）      │
└────────────────────────────────────────────────────┘
```

**起点（center 基因组）**：GA 全量轮（r5+r6 共 264 轮）最高分的那份基因组
（目白善信 71415.6 分）。新算法从山顶出发找更高的山头，不从山脚重新爬。

## 快速开始

### CI 跑（推荐，模拟器在云端自动编译）
GitHub 仓库页 → Actions → **lab-smoke** → Run workflow → 选优化器和预算。
产物在 artifact 里（`results/*.json`，含最优基因组 TOML 和完整尝试历史）。

### 本地跑
```bash
pip install -r requirements.txt
export UMA_BENCH_BIN=/path/to/bench_base   # 编译好的模拟器基准工具
python experiments/compare.py --optimizers cmaes,tpe,sa,cem --budget 60 --uma 111501
```

### 最优基因组回放出育成过程报告
```bash
python experiments/replay_report.py --genome best_genome.toml --uma 111501 --seed 1001
# 产出 replay/育成过程报告.md：逐回合决策表
```

## 赛马规则

- **同预算**：每个优化器最多 N 次评估，一次评估 = 3 个种子 × 20 局（smoke 档）。
- **CRN 同种子**：所有优化器评估用同一组随机种子，配对比较，噪声对冲。
- **缓存**：相同基因组不重复评估（哈希去重）。
- **holdout 终审**：full 档冠军再跑独立种子集，防止过拟合评估种子。
- **罚分**：fitness = 平均分 − 800 × 比赛失败率（与 Rust GA 完全同式，成绩可直接对表）。

## 文件地图

| 路径 | 干什么 |
|---|---|
| `lab/space.py` | 70 字段搜索空间（哪些参数可动、范围多少） |
| `lab/genome.py` | 参数向量和 TOML 互转（喂给模拟器的语法） |
| `lab/evaluator.py` | 跑分、缓存、罚分、holdout |
| `optimizers/` | 四个算法选手 |
| `experiments/compare.py` | 赛马入口 |
| `experiments/replay_report.py` | 最优基因组回放出育成过程报告 |
| `docs/algo-selection.md` | 300+ 算法清单的筛选结论（哪些有用为什么） |

## 成绩基准（对表用）

| 基准 | 分数 | 说明 |
|---|---|---|
| preset 手写策略 | ~64752 | 出厂参数 |
| GA r5/r6 冠军 | **71415.6** | 当前天花板（center 起点） |
| 本实验室目标 | > 71415.6 | full 档 holdout 显著提升才算数 |

成绩判定遵守噪声纪律：提升必须过 CRN 配对检验，单种子波动 ±2100~3000 不算数。
